TextPrinterMSDF does not render inside the raw INI rectangle: by default it auto-resizes that rectangle using textpos, then applies h_anchor / v_anchor / h_align. Load the exact FontMSDFMetrics.buf and set game resolution + effective_dpi to match the game. Canvas glyph shapes are still approximations; positions, advances and bounding-box placement use the MSDF metrics.

Render calibration

Shader ScreenScaling = effective_dpi / 120 only when effective_dpi > 120; otherwise it is 1. Match the actual backbuffer size, not your monitor model. Auto-resize follows TextPrinterMSDF defaults.
The first action aligns the actual glyph-bounds center, not the raw INI rectangle. Load the game's MSDF metrics for the most accurate result. The second action preserves the previous rectangle-centering behavior.
The first four floats are the INI anchor rectangle, not the visible glyph bounds. The visible text can be vertically offset because MSDF positions glyphs from the ascender-based baseline. Use “Center visible text on hitbox” to correct the final rendered glyph position. Arrow keys nudge it; Shift uses a larger step. Positive clip Y goes upward.
